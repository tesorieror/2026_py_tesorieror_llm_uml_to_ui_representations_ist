# Historical Dependency Files

The files `requirements.txt` and `_requirements.txt`
are retained solely for provenance and historical
reproducibility documentation.

Both contain an editable Git dependency referring
to the original private research repository.

These files are not intended as public installation
instructions and should not be used to install this
replication package.

For the public replication package, use
`requirements-replication.txt` together with the
local package source and `pyproject.toml`.

Independent end-to-end installation and execution
of the scientific analyses have not yet been
validated.

Original scientific artifacts and dependency
versions have not been altered by this notice.
